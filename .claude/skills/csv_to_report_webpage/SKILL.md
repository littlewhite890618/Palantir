# csv_to_report_webpage — 任意 CSV 轉可搜尋展開網頁

## 用途（通用，不限主題）
把**任何** CSV 變成一頁好讀的網站：每列是一張卡片，收合時顯示大標題＋標籤＋摘要欄，
**點擊展開**看完整欄位；頂部有**即時搜尋框**（比對所有欄位）。欄位不需固定、不限中文、
不限主題——不管是補助案、訂單、名單、log、還是任何表格都能吃。輸出是**自包含 HTML**
（inline CSS/JS、`@media` 深淺色、responsive），適合直接用 **Artifact 工具發布**成網頁連結。

**設計原則：零設定也能跑。** 腳本會自動判斷哪一欄當標題、哪一欄當標籤、哪些當摘要；
判斷不到就用通用預設（標題＝第一欄、沒有標籤/摘要就不顯示、其餘欄位全部照列在展開區）。
需要精準控制時再用參數覆寫。

## 什麼時候用
- 使用者說「把這個 CSV／結果整理成一頁好讀的網頁」「做成網站給我看/對照/搜尋」。
- 手上有**任何** CSV（萃取結果、清單、匯出、抽樣、log…）要給人瀏覽。
- 補助案專案：跑完 `extract_fields.py` / `postprocess.py` 的 `fields_extracted.csv`、或任何被移除/抽樣清單。

## 流程（我要做的兩步）
1. **產生 HTML**：跑下面的腳本，讀 CSV 產出 HTML。
2. **發布**：用 `Artifact` 工具把產出的 HTML 檔發布（拿到 claude.ai 連結）。
   - 要更新既有網頁就用**同一個檔路徑重發布**（保持同 URL），或帶 `url=` 指到舊 artifact。

## 執行
```bash
python scripts/build_report.py --in <你的.csv>
```
輸出預設為輸入檔同名 `.html`。常用參數（多半可省，會自動偵測）：
```bash
python scripts/build_report.py \
  --in fields_extracted.csv \
  --out report.html \
  --page-title "補助須知 9 欄 · 去重後" \
  --title-col 標題 \
  --tag-col 部門 \
  --summary-cols 補助金額上限,申請截止日期 \
  --fail-col 萃取模型 \
  --exclude-cols 規則交叉檢查,備註
```

## 參數（都可省，括號內為自動偵測預設）
- `--title-col`（標題/title/name/計畫名稱，否則第一欄）：每列大標題。
- `--tag-col`（部門/機關/申請機關）：標題旁小標籤；無則不顯示。
- `--summary-cols`（補助金額上限,補助比例,申請截止日期）：**收合時**就顯示的摘要欄（有值才顯示）。
- `--fail-col`（萃取模型）：**此欄為空**的列視為「未完成」、左邊會標橘色高亮，統計列也會分「完成/未完成」。用 `--fail-col ""` 關閉此行為。
- `--exclude-cols`：展開時**不**顯示的欄（例如內部旗標）。
- `--page-title`：頁面大標題（預設＝輸入檔名）。
- 值以 `http(s)://` 開頭的欄會自動渲染成可點連結；超過 120 字的長欄位會變成可捲動框。

## 對本專案 fields_extracted.csv 的預設效果
不帶任何參數直接跑就已合理：標題＝`標題`、標籤＝`部門`、摘要＝`補助金額上限/補助比例/申請截止日期`、
`萃取模型` 為空的失敗列會高亮。展開看全部 9 欄＋連結。

## 依賴
純標準庫（`csv`/`html`/`argparse`），**免安裝**。

## 已知坑
- Windows console 是 cp950，腳本本身只寫檔不 print 中文內容（只印 ASCII 摘要），不會踩編碼雷。
- CSV 請用 `utf-8`（BOM 可有可無，腳本用 `utf-8-sig` 讀）。
- 發布前若內容含真實個資／可被誤認為官方文件的頁面，先確認再發布（Artifact 規範）。
