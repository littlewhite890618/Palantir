# 時程金額萃取 — 需求與規格文件（SPEC）

> 本檔用英文檔名（SPEC.md）以確保在本環境能持久保存（中文檔名存不住）。
> 內容對應引擎：`scripts/extract_schedule_amount.py`。修改引擎時請同步更新本檔。

---

## 1. 目標

從各政府機關的「申請須知」檔案（PDF / DOCX / ODT / ZIP）中，自動萃取每個補助計畫的
**時程（申請/執行時間）** 與 **金額（補助上限）**，彙整成一份主檔 CSV。
需可重複執行、可固定排程。

---

## 2. 輸入 / 輸出

### 輸入清單 CSV（欄位：`部門,檔案名稱,連結`）
| 檔案 | 內容 |
|---|---|
| `data/pilot_input.csv` | 試點 10 筆（跨部門抽樣，調校用） |
| `data/stage2_input.csv` | 產業發展署 67 筆 |
| `data/stage3_input.csv` | 商發署46 + 數位部17 + 技術司12 = 75 筆 |
| `data/stage4_input.csv` | 中小署 + 臺北 + CPC + 各縣市 = 45 筆 |

下載的檔案快取在 `data/pdf_cache/`（以 `部門_名稱[:60]_md5(url)[:8].副檔名` 命名），已存在則跳過重抓。

### 輸出主檔（`時程金額萃取結果.csv`，UTF-8-SIG）
欄位順序：
```
部門, 計畫名稱, 原始檔名, 檔案類型, 下載狀態, 萃取狀態,
時程_命中關鍵字, 時程_值, 時程_型態,
金額_命中關鍵字, 金額_值, 金額_型態, 備註, 連結
```
另產生 `時程金額萃取結果_debug.csv`（`部門,原始檔名,時程脈絡,金額脈絡`）供人工核對命中上下文。

### 輸出規則
- **一檔一時程一金額**：每個檔案只輸出一組。
- **金額取最高上限**：全文掃描「上限語境」的萬元金額，取最大值。
- **計畫名稱**：取 PDF 內文標題行（比 PDF metadata 可靠），退而用檔名 / metadata。
- **部門**：取自來源清單 CSV 的檔名前綴，**不從 PDF 內文抓**。
- 主控台 cp950 無法印中文 → 一律寫檔，不在 console 印中文。

## 3. 「關鍵字附近會比較找得到」— 錨點策略

引擎不是全文亂找，而是**先定位錨點關鍵字，再在錨點後方一段視窗內找值**。
所以「值」通常就緊貼在這些關鍵字之後。

### 3.1 時程錨點（`TIME_ANCHORS`，依可靠度排序，越前面越優先）
```
公告受理日期、收件截止日期、收件期間、收件日期、收件地點及截止日期、
收件、服務窗口、申請期間、受理期間、計畫申請時間、申請時間、受理至、
計畫期程、執行期程、本期執行時間、執行期間、計畫時程不超過
```
- 視窗：錨點後 **200 字**內找時程值。
- **排序刻意把「執行期間 / 執行期程」放最後** → 因為契約範本裡「執行期間」旁常是條款用語（例如「執行期間屆滿後保管X年」），容易誤抓，故讓「申請/收件/受理」這種真排程優先。

### 3.2 金額錨點（`MONEY_ANCHORS`）
```
補助金額上限、補助上限、補助額度、補助經費、輔導經費、申請額度
```
- 視窗：錨點後 **220 字**內找金額值。
- 但金額另有「全文上限掃描」不受錨點限制（見 §5.2 A）。

### 3.3 新關鍵字探勘（`discover_new`）
若某檔時程或金額**沒命中**，引擎會回頭找「值旁邊的標籤詞」並記到備註，供人擴充錨點：
- 時程標籤特徵：詞尾含 `時間 / 期間 / 期程 / 日期 / 期限 / 受理 / 收件 / 截止 / 起訖`
- 金額標籤特徵：含 `補助 / 經費 / 額度 / 金額 / 上限 / 比例 / 補貼 / 款項 / 獎勵`

## 4. 時程分為幾種格式（型態）

共 **6 種型態**，分「強型」與「弱型」；**強型先試、弱型後試**（弱型易誤抓，需過濾）。

### 強型（4 種，可靠，優先採用）
| 型態 | 說明 | 範例 |
|---|---|---|
| `隨到隨受理` | 開放式受理 | 隨到隨受理、即日起、額滿為止、隨收隨審 |
| `年月日` | 完整日期（含起訖） | 民國115年1月1日、114年1月3日至114年3月3日 |
| `年月` | 到月 | 115年10月、110年1月~114年8月 |
| `日期(斜線)` | 斜線日期 | 114/5/26、105.10.01-106.01.31 |

### 弱型（2 種，需過濾契約 boilerplate 才採用）
| 型態 | 說明 | 範例 |
|---|---|---|
| `期程長度` | 執行時長 | 2年、12個月、8個月 |
| `純年份` | 只有年度 | 115年度 |

### 弱型的過濾（避免抓到條款用語）
- **來源壓制** `TIME_SUPPRESS_WEAK = {經濟部產業發展署, 經濟部產業技術司}`：這兩個來源是契約範本，弱型時程一律不採，只採日期。
- **前文黑名單** `TIME_BOILERPLATE_PRE`：值前面若接
  `近 / 前 / 完畢後 / 完成後 / 核定後 / 收件日 / 簽約後 / 保管 / 查核 / 查證 / 屆滿 / 存續 / 逾` → 丟棄。
- 另排除前文含 `例如 / 例： / 編列 / 科目 / 預算 / 比例 / 保證 / 結束日後 / 請款 / 月數 / 之X%`。

## 5. 金額分為幾種格式（型態）

共 **3 種型態**，用三段策略找，優先取「萬元上限」的最大值。

### 5.1 三種型態（`MONEY_PATTERNS`）
| 型態 | 說明 | 範例 |
|---|---|---|
| `萬元金額` | 以萬元計 | 新臺幣2,000萬元、700萬元、上限100萬元 |
| `百分比` | 補助比例 | 百分之50、50%、9成 |
| `元金額` | 以元計（≥4位數） | 新臺幣4,800,000元 |

### 5.2 找金額的三段策略（依序）
- **A) 全文上限掃描（主力，取最高）**：全文找
  `上限/最高/至多/不超過/不得超過 + X萬元`，或 `X萬元 + 為上限/為限/整`，**取最大值**。
- **B) 金額錨點視窗萬元**：在 §3.2 錨點後視窗找萬元，取最高（補 A 的漏）。
- **C) 無萬元 → 錨點旁百分比/元**：退而找百分比或元金額。

### 5.3 金額過濾
- **下限**：`< 20萬` 視為子項/雜項上限（專利、差旅等），不當計畫補助上限。
- **排除語境** `CAP_EXCLUDE`：值前若含
  `資本額 / 出資額 / 實收資本 / 一億 / 營業額 / 設備 / 設施 / 器材 / 專利 / 每項 / 單價 / 單筆 / 每人 / 雜費 / 差旅 / 租金` → 丟棄（那是門檻/成本，不是補助上限）。

## 6. 計畫名稱與部門

- **計畫名稱**（`pick_title`）優先序：
  1. 原始檔名若同時含「申請須知」+（計畫/補助/SBIR/獎勵/研發）→ 直接用檔名
  2. 內文前 25 行含「申請須知」的乾淨標題（長度 6~45、非目錄行、非前言/條款句）
  3. 內文含 計畫/補助/獎勵/要點 的乾淨標題
  4. 檔名含 計畫/須知/補助/獎勵/要點
  5. PDF metadata（排除機構名/軟體名）
  6. 退回檔名或第一個可行行
- **部門**：來源清單 CSV 提供，不從 PDF 抓。

## 7. 這次的「4 種漏抓狀態」重跑需求

使用者人工核對後，在主檔 `備註` 欄標了 4 種漏抓狀態，要求**只針對這些列**用加強版引擎重跑：

| 備註標記 | 意思 | 應補抓 |
|---|---|---|
| 時程與金額都有但沒抓到(用國字寫) | 兩者都有、寫成國字 | 國字時程（一年六個月）＋ 國字金額（一百萬元 / 總經費百分之五十） |
| 時程沒有金額有但沒抓到(用國字寫) | 只有金額、國字 | 國字金額（百分之五十）；時程確實無 → 留空 |
| 時程與金額皆有但沒抓到金額 | 金額漏抓 | 特殊語境（二百萬元**為上限**） |
| 時程與金額皆有但沒抓到時程 | 時程漏抓 | 期程長度語境（**不超過3年**為原則） |

### 已定位的引擎缺口 → 已解（2026-07-20，`rerun_missing.py` 重跑 65/68 補回）
1. **國字數字**：新增 `cn2int()` ＋ 只在「數字＋單位」觸發的國字轉換 → `一百萬元→100萬元`、`總經費百分之五十→50%`、`一年六個月→1年6個月`。輸出一律阿拉伯。✅
2. **「不超過X年為原則」漏時程**：`find_time` 加 Pass1.5 `DUR_LIMIT`（`不超過/以/最長 X年為原則`，國字+阿拉伯），**不受 `TIME_SUPPRESS_WEAK` 壓制** → 產發署 49/49 全補回。✅
3. **「X萬元為上限」漏金額**：`CAP_PAT` 支援國字＋允許 `萬元(含稅)為上限` 夾註記；上限 floor 20→10 萬。✅
4. **CJK 相容表意字 / 全形％（真兇）**：部分 PDF 字元落在 U+F900–FAFF（`不`=U+F967、`為`=U+F98E）看似正常卻比對失敗；`百分之五十` 有時是全形 `50％`(U+FF05)。→ `normalize()` 加 **`unicodedata.normalize("NFKC")`** 一次折平（相容字→標準、全形→半形、％→%）。✅

### 定向 override 補回（依使用者指示，`rerun_missing.py` 的 `OVERRIDE_MONEY`）
- **aoc-360**：無單一「補助上限」，依指示取**輔導費上限表格最高** → `20萬元`。✅
- **aoc-323**：依指示取**輔導款最高**（排自籌款）→ `45萬元`。✅
（作法：僅當通用 `find_money` 沒抓到才套用；不動全域 `MONEY_ANCHORS`，避免污染其他列如 aoc-478。）

### 最終結果：67 / 68 補回
仍 1 筆未補（使用者指示可略）：
- **臺北市政府推薦微型…登錄申請須知**：全文為「推薦登錄創櫃板作業須知」，**實際無補助金額、無執行期程**（僅5人審查/3年追蹤/90日失效）→ 狀態標記疑有誤。

### 重跑工具
- `scripts/rerun_missing.py`：以**行號**從 stage2/3/4 精選 68 列（`FLAG` 內含行號→狀態），走快取 PDF ＋ 加強引擎，輸出 `data/rerun_result.csv`（時程/金額 new 值、脈絡、是否補到）。重跑一律 `weak_ok=True`。

## 8. 環境限制（務必遵守）

- **中文檔名在本環境存不住**：Write 工具寫中文檔名會靜默失敗；跨環境循環也會遺失。
  → 所有新建檔案**一律用英文檔名**（主檔歷史上叫 `時程金額萃取結果.csv`，若重生建議改英文名）。
- 主控台 cp950 不能印中文 → 輸出一律寫檔（UTF-8-SIG）。
- 老政府站 TLS 需 `LegacyTLSAdapter`（SECLEVEL=1、CERT_NONE）。
- 部分站需特殊處理：雲林（Cloudflare→Selenium 非 headless）、reurl.cc（JS 轉址）、Google Drive（uc?export=download）。

## 9. 執行方式

```bash
# 預設讀 pilot_input.csv，輸出到 時程金額萃取結果.csv
python scripts/extract_schedule_amount.py [輸入CSV] [輸出CSV]
```
主檔以 append 方式寫入，並以「連結」去重（已在主檔的 URL 會跳過）。
